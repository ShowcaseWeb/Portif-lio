Sobre mim

Movido pela tecnologia,
guiado pela curiosidade

Sou estudante de Análise e Desenvolvimento de Sistemas, apaixonado por tecnologia, inovação e pela criação de soluções digitais que geram resultados reais.

Minha stack principal abrange Java com Spring Boot para o back-end, React no front-end, Python para análise de dados e automações, e bancos de dados relacionais com PostgreSQL. Acredito num aprendizado contínuo e colaborativo, cada projeto é uma oportunidade de crescer.

Tenho especial interesse em Inteligência Artificial, desenvolvimento web full stack e modelagem de banco de dados. Quando não estou codando, estou estudando novas arquiteturas de software ou contribuindo com projetos de código aberto.
